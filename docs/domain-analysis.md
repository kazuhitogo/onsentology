# Phase 1: ドメイン分析 & 要件定義

> **免責事項**: 本ドキュメントおよび本リポジトリの成果物は、温泉に関する**法制度・分類体系を情報工学的にモデル化**することを目的とした技術検証物です。**医療的助言ではありません**。適応症・禁忌症の記載はすべて環境省「掲示基準」（環自総発第1407012号）の条文内容の引用であり、個人の健康判断の根拠として用いるべきものではありません。温泉療養を行う場合、環境省通知自体が「専門的知識を有する医師による指示、指導のもとに行うことが望ましい」と定めています。

一次情報の詳細は [research-spring-quality.md](./research-spring-quality.md)（制度・分類）と [research-onsen-data.md](./research-onsen-data.md)（実データ）に分離してある。本ドキュメントはそこから**オントロジー設計の判断だけ**を抽出したものである。

## 1. モデル化のスコープ

| 含める | 含めない |
|---|---|
| 温泉法・鉱泉分析法指針・掲示基準に**明文の根拠がある概念** | 「効く／効かない」の医学的評価 |
| 掲示用泉質10種とその成分基準値 | 個々の施設の口コミ・主観的評価 |
| 泉温・液性・浸透圧の3分類軸 | 価格、営業時間などの動的な情報 |
| 法定湯使い5類型（加水・加温・循環ろ過・入浴剤・消毒） | 「源泉かけ流し」を**一次概念として**扱うこと（後述 3-3） |
| 適応症・禁忌症（一般／泉質別／含有成分別の3階層） | 「伝統的適応症」の具体的内容（知事裁量のため一般化不能） |
| 法定の入浴・飲用プロトコル（回数・時間・安静・水分） | 「はしご湯」を公的概念として扱うこと（後述 3-4） |

## 2. 掲示用泉質10種の判定基準（オントロジーの中核）

`onsen:SpringQuality` の10インスタンスと、その判定に使う成分閾値。出典はすべて鉱泉分析法指針（平成26年改訂）第1-3表および1-3節。

| 泉質 | 判定条件（温泉水1kg中） |
|---|---|
| 単純温泉 | 溶存物質 1,000mg **未満** かつ 泉温 25℃以上（現地pH 8.5以上なら「アルカリ性単純温泉」） |
| 塩化物泉 | 溶存物質 1,000mg以上 かつ 陰イオン主成分が Cl⁻ |
| 炭酸水素塩泉 | 溶存物質 1,000mg以上 かつ 陰イオン主成分が HCO₃⁻ |
| 硫酸塩泉 | 溶存物質 1,000mg以上 かつ 陰イオン主成分が SO₄²⁻ |
| 二酸化炭素泉 | 遊離二酸化炭素 1,000mg以上 |
| 含鉄泉 | 総鉄イオン（Fe²⁺+Fe³⁺） 20mg以上 |
| 酸性泉 | 水素イオン（H⁺） 1mg以上 |
| 含よう素泉 | よう化物イオン（I⁻） 10mg以上 |
| 硫黄泉 | 総硫黄（S） 2mg以上（`[H₂S] > [HS⁻]+[S₂O₃²⁻]` なら「硫化水素型」） |
| 放射能泉 | ラドン 8.25マッヘ単位以上（50マッヘ以上で「放射能」、未満は「弱放射能」） |

**「主成分」= ミリバル（mval）値が最大のもの**。塩類泉3種は陽イオン主成分でさらに細別される（ナトリウム－／カルシウム－／マグネシウム－ など）。

### 分類の3軸（泉質名に併記される）

掲示上の完全な泉質表記は `<泉質名>（<浸透圧><液性><泉温>）` という**合成構造**を取る。
実例（指針 p.158）: `含硫黄－ナトリウム・カルシウム－塩化物温泉（高張性弱アルカリ性高温泉）`

- 泉温: 冷鉱泉 <25℃ / **低温泉** 25–34℃ / 温泉 34–42℃ / 高温泉 ≧42℃
- 液性: 酸性 pH<3 / 弱酸性 3–6 / 中性 6–7.5 / 弱アルカリ性 7.5–8.5 / アルカリ性 ≧8.5
- 浸透圧: 低張性 <8,000mg/kg / 等張性 8,000–10,000 / 高張性 ≧10,000

→ **設計判断**: 泉質名と3軸を独立プロパティとして持ち、表示時に合成する。3軸は生の測定値（pH・泉温・溶存物質）から**推論で導出**できるので、Phase 4 の SPARQL CONSTRUCT ルールの題材にする。

> 泉温 25–34℃ の正式名称は「低温泉」。「微温泉」は指針に存在しない（当初計画の想定を訂正）。
> なお「温泉」という語が上位概念と 34–42℃ 区分名の両方に使われるため、URI は `onsen:MildTemperatureSpring` のように区分名を明示的に分ける。

## 3. 設計上の5つの落とし穴と対処

実データ調査（15温泉地）で発覚した、素朴なモデルが破綻するケース。**これが記事の技術的な山場になる。**

### 3-1. 施設と源泉を分離しないと pH が表現できない

草津温泉は同一温泉地内で 湯畑源泉 pH2.08 / 万代源泉 pH1.7 / 煮川源泉 pH2.1。
1施設が複数源泉を使い分ける（御座之湯は湯畑源泉と万代源泉を木之湯／石之湯で使用）。

→ `onsen:Facility`（施設）と `onsen:SpringSource`（源泉）を**別クラス**にし、成分値は源泉側に持たせる。施設から泉質へは `usesSource → hasQuality` の2ホップになるので、OWL のプロパティチェーン公理で1ホップに畳む。

### 3-2. 成分値には測定地点と分析年月日が必須

掲示基準4.留意事項は、掲示内容は**利用施設**での分析結果を原則としつつ、差異がなければ**ゆう出口**の値でもよいとし、源泉ベースで判断した場合はその旨を明示せよと定める。つまり同一施設でも源泉ベースと浴槽ベースで値が異なりうる。
また温泉成分分析は**10年以内**ごとに受け直す（温泉法施行令第1条）。

→ 測定値には `onsen:measurementPoint`（源泉／利用施設）と `onsen:analysisDate` を必ず付ける。値だけをぶら下げる設計は不十分。

### 3-3. `isKakenagashi` を boolean 単独で持つと誤推論する

「源泉かけ流し」は**法令上の定義が存在しない**（施行規則第10条が掲示を義務づけるのは加水・加温・循環ろ過・入浴剤・消毒の5類型のみ）。
決定的な反例: **有馬温泉 金の湯は放流式（かけ流し）でありながら、加水・加温・塩素消毒をすべて実施**している。「かけ流し＝無加工」ではない。

→ 対処は2段構え。
1. 法定5類型を `onsen:TreatmentDeclaration`（湯使い宣言）として**中間ノードに reify** し、`treatmentType` / `isApplied`（bool）/ `reason`（理由文）を持たせる。掲示が「その旨**及びその理由**」を要求するため、単なる boolean では法定要件を表現できない。
2. 「源泉かけ流し」は (a) 事業者の自主表示 `onsen:claimsKakenagashi` と、(b) 法定5類型の否定から**導出される** `onsen:isUnmodifiedSupply` に分離する。当初計画の `isKakenagashi` は (a) に相当する自称ラベルとして残す。

### 3-4. 「はしご湯」は俗語であり、制約は法定プロトコルから導出する

一次情報4文書に「はしご湯」「湯めぐり」という語は1件も出現しない。一方、制約の根拠は明確に存在する。

| 法定規定 | 内容 | はしご湯への含意 |
|---|---|---|
| 入浴回数 | 開始後数日間は1日1–2回、慣れて2–3回まで | 巡浴は容易に上限超過 |
| 入浴時間 | 初め3–10分、慣れて15–20分まで | 1回ごとの時間管理 |
| 入浴後 | 保温と**30分程度の安静** | 連続巡浴と両立しにくい |
| 入浴後 | コップ一杯の水分補給 | 回数に比例して脱水リスク |
| 入浴温度 | 高齢者・高血圧・心疾患・脳卒中経験者は42℃以上を避ける | 高温泉を含む巡浴の制約 |
| 湯あたり | 開始後おおむね**3日〜1週間**で気分不快・不眠・消化器症状・皮膚炎。出現中は中止か回数減 | 巡浴の中断判断基準 |
| 入浴後 | 刺激の強い泉質（**酸性泉・硫黄泉等**）は肌の弱い人は洗い流す | 異泉質連続利用時の皮膚負担 |

→ `onsen:BathingProtocol` に法定の数値制約を持たせ、「はしご湯プラン」は**この制約を満たす巡回順序を計算する問題**として定式化する。これが第2話の主題。

### 3-5. 泉質→適応症は決定論的でない

掲示基準は適応症の掲示内容を「引き続き**知事の判断に委ねる**」と明記し、「伝統的適応症」という第3カテゴリの存在も認めている。飲泉には温泉法第18条の**飲用許可**が別途必要で、許可のない施設は飲用の適応症・禁忌症を掲示してはならない。

→ 「基準上の泉質別適応症」（規範・`SpringQuality` に付与）と「個別施設の実際の掲示内容」（実測・`Facility` に付与）を分離する。飲用可否は `onsen:drinkingPermitted` として**施設側**の属性にする。

### 3-6. 補足: 泉質名の新旧混在と造成泉

- 鳴子・滝の湯は旧泉質名のみ公表（`酸性含明礬・緑礬-芒硝硫化水素泉`）、箱根は新旧併記。→ `onsen:legacyQualityName` を別ラベルとして保持。
- 箱根大涌谷は**造成泉**（噴気＋温泉用水を混合して製造、自噴分が総湯量の約30%）。→ `onsen:isArtificiallyProduced` フラグ。
- 玉川温泉は源泉100%／50%／弱酸性の浴槽が並立し、飲泉は38倍希釈。→ `onsen:Bath`（浴槽）クラスと `onsen:dilutionRatio`。

| R9 | 刺激の強い泉 同士の連続 → 非推奨（`incompatibleWith`） | 順序関係 | 掲示基準 2.(2)①エ(ア) |
| R10 | 巡浴プランが 1日の入浴回数上限・累積入浴時間・42℃制約・安静時間 に違反 → 警告 | 数値制約 | 掲示基準 2.(2)①イ・エ |

## 5. ペルソナ定義: 温泉爺（おんせんじい）

### 5-1. キャラクター設定

| 項目 | 設定 |
|---|---|
| 呼称 | 温泉爺（おんせんじい） |
| 来歴 | 元・分析化学の技術者。定年後に温泉地へ隠居し、生涯で1,200湯を巡った。温泉分析書を読むのが趣味。 |
| 一人称 | わし |
| 二人称 | あんた（親しみを込めて） |
| 語尾 | 「〜じゃ」「〜のう」「〜じゃろ」「〜かい」。過剰に使わず、3文に1回程度。 |
| 知識の芯 | **数値と出典で語る**。「体に良い」ではなく「pH2.08、水素イオンが基準の何倍」と言う。 |
| 頑固さ | 根拠のない効能話と、湯使いを隠す施設を嫌う。「かけ流しと書いてあっても掲示を読め」が口癖。 |
| 温かみ | 相手の体調を必ず先に気にする。無理な湯めぐりは止める。 |
| 弱点 | 話が長い。分析書の話を始めると止まらないので、自分で「……おっと、湯が冷めるわい」と切り上げる。 |

### 5-2. 発話ルール（システムプロンプトの制約に落とす）

**必ず守ること**
1. 泉質・pH・泉温を語るときは、**オントロジー検索ツールが返した値のみ**を使う。ツールが値を返さなかった項目は「そこは掲示を見んと分からんのう」と正直に言う（幻覚の禁止）。
2. 適応症・禁忌症に触れるときは、それが**環境省の掲示基準に基づく区分**であることを一度は明示する。
3. 医学的な断定をしない。「治る」「効く」と言わず「掲示基準では〜が適応症に挙げられておる」と言う。
4. 一般的禁忌症（発熱時・急性増悪期など）に該当しそうな相談には、**まず医師に相談せよ**と伝える。
5. 回答の最後に、根拠にした施設名・源泉名を挙げる。

**やらないこと**
- 出典のない数値を出す
- 「湯あたり」を軽視して連続入浴を勧める
- 相手の症状を診断する

### 5-3. トーンの実例

> 「ほう、肌がガサガサかい。……あんた、草津の湯畑源泉に長く浸かったじゃろ。あれは pH2.08、水素イオンが療養泉の基準を優に超える酸性泉じゃ。掲示基準でも酸性泉の禁忌症に『高齢者の皮膚乾燥症』が挙げられておる。
> わしが勧めるのは仕上げの湯じゃ。四万の積善館は昔から『草津の仕上げ湯』と呼ばれてな、ナトリウム・カルシウム–塩化物・硫酸塩温泉。塩化物泉と硫酸塩泉の適応症には『皮膚乾燥症』が入っておる。
> ……おっと、話が長うなった。湯が冷めるわい。医者にかかっとる薬があるなら、まず主治医に一言な。」
