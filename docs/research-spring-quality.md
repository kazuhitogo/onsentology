## 1. 温泉法上の「温泉」の定義と療養泉との違い

### 1-1. 「温泉」の定義（温泉法第2条・別表）

温泉法（昭和23年法律第125号）第2条により、温泉とは
**「地中からゆう出する温水、鉱水及び水蒸気その他のガス（炭化水素を主成分とする天然ガスを除く。）」**
であって、次の**温度または物質のいずれか一つ**を満たすものと定義されます。[環境省-定義] [指針2014 第1-1表]

**(1) 温度基準**: 温泉源から採取されるときの温度が**摂氏25度以上**

**(2) 物質基準**（以下のいずれか一つ、温泉水1kg中）

| 物質名 | 含有量（1kg中） |
|---|---|
| 溶存物質（ガス性のものを除く） | 総量 **1,000 mg以上** |
| 遊離炭酸（CO2、遊離二酸化炭素） | **250 mg以上** |
| リチウムイオン（Li⁺） | 1 mg以上 |
| ストロンチウムイオン（Sr²⁺） | 10 mg以上 |
| バリウムイオン（Ba²⁺） | 5 mg以上 |
| フェロ又はフェリイオン（総鉄イオン Fe²⁺+Fe³⁺） | 10 mg以上 |
| 第一マンガンイオン（マンガン(II)イオン Mn²⁺） | 10 mg以上 |
| 水素イオン（H⁺） | 1 mg以上 |
| 臭素イオン（臭化物イオン Br⁻） | 5 mg以上 |
| 沃素イオン（ヨウ化物イオン I⁻） | **1 mg以上** |
| ふっ素イオン（フッ化物イオン F⁻） | 2 mg以上 |
| ヒドロひ酸イオン（ヒ酸水素イオン HAsO₄²⁻） | 1.3 mg以上 |
| メタ亜ひ酸（HAsO₂） | 1 mg以上 |
| 総硫黄(S) [HS⁻+S₂O₃²⁻+H₂Sに対応するもの] | **1 mg以上** |
| メタほう酸（HBO₂） | 5 mg以上 |
| メタけい酸（H₂SiO₃） | 50 mg以上 |
| 重炭酸そうだ（炭酸水素ナトリウム NaHCO₃） | 340 mg以上 |
| ラドン（Rn） | 20（百億分の1キュリー単位）以上<br>= 20×10⁻¹⁰ Ci = **74 Bq以上**（**5.5マッヘ単位以上**） |
| ラジウム塩（Raとして） | 1億分の1 mg以上（1×10⁻⁸ mg以上） |

出典: [環境省-定義] https://www.env.go.jp/nature/onsen/point/ ／ ラドンのBq・マッヘ換算値は [指針2014] 第1-1表 p.1 に明記（`20×10-10 Ci=74 Bq 以上 (5.5 マッヘ単位以上)`）

### 1-2. 「療養泉」の定義（鉱泉分析法指針 第1-2表）

療養泉とは、**温泉（水蒸気その他のガスを除く。）のうち、特に治療の目的に供しうるもの**で、次の温度または物質を有するものです。[環境省-定義] [指針2014 第1-2表 p.3]

**(1) 温度基準**: 源泉から採取されるときの温度が**摂氏25度以上**

**(2) 物質基準**（以下のいずれか一つ、1kg中）

| 物質名 | 含有量（1kg中） |
|---|---|
| 溶存物質（ガス性のものを除く） | 総量 **1,000 mg以上** |
| 遊離二酸化炭素（CO₂） | **1,000 mg以上** |
| 総鉄イオン（Fe²⁺+Fe³⁺） | **20 mg以上** |
| 水素イオン（H⁺） | **1 mg以上** |
| よう化物イオン（I⁻） | **10 mg以上** |
| 総硫黄(S) [HS⁻+S₂O₃²⁻+H₂Sに対応するもの] | **2 mg以上** |
| ラドン（Rn） | 30×10⁻¹⁰ Ci = **111 Bq以上**（**8.25マッヘ単位以上**） |

出典: [環境省-定義] https://www.env.go.jp/nature/onsen/point/ ／ [指針2014] p.3

### 1-3. 「温泉」と「療養泉」の違い（オントロジー設計上の要点）

| 観点 | 温泉（温泉法上の温泉） | 療養泉 |
|---|---|---|
| 根拠 | 温泉法第2条・別表（**法律**） | 鉱泉分析法指針（**行政指針**）／掲示基準通知 |
| 対象 | 温水・鉱水**および水蒸気その他のガスを含む** | 温泉のうち**水蒸気その他のガスを除く** |
| 判定物質の種類数 | 19項目（溶存物質総量＋18物質） | 7項目 |
| 閾値の厳しさ | 緩い（例: 遊離CO₂ 250mg、総硫黄 1mg、総鉄 10mg、Rn 5.5マッヘ） | **厳しい**（例: 遊離CO₂ 1,000mg、総硫黄 2mg、総鉄 20mg、Rn 8.25マッヘ） |
| 泉質名 | 療養泉基準を満たさない場合、**泉質名はつかない** | 泉質名がつく（掲示用泉質10種） |
| 該当しない場合の表記 | — | 温泉分析書に「温泉法上の温泉」「温泉法第2条に該当する温泉」等と記載 [JSA-泉質] |

**重要な差分**: 療養泉の物質基準には、温泉法別表にある**リチウム・ストロンチウム・バリウム・マンガン・臭化物・ふっ化物・ひ酸・メタほう酸・メタけい酸・炭酸水素ナトリウム・ラジウム塩が含まれません**。逆に、療養泉のよう化物イオン基準（10mg）は温泉法別表（1mg）より10倍厳しい値です。

> **注意（オントロジー実装上の落とし穴）**: 日本語版Wikipedia「鉱泉分析法指針」の療養泉の表は**平成26年改訂前の古い内容**で、銅イオン（1mg）・アルミニウムイオン（100mg）を含み、よう化物イオンを欠いています。**平成26年改訂で銅・アルミニウムは療養泉の特殊成分から削除され、よう化物イオンが追加されました**（[環境省-定義] および [指針2014] 第1-2表・第1-3表で確認）。一次情報を採用すべきです。

| # | 掲示用泉質名 | 成分基準値（温泉水1kg中） | 根拠 |
|---|---|---|---|

| 4 | **硫酸塩泉** | 溶存物質（ガス性のものを除く）**1,000 mg以上**、かつ**陰イオンの主成分が硫酸イオン（SO₄²⁻）** | [指針2014] 1-3(1)3) |

| 10 | **放射能泉** | **ラドン（Rn）30×10⁻¹⁰ Ci = 111 Bq以上（8.25マッヘ単位以上）** | [指針2014] 第1-3表(f) |

**タスク前提の検証結果**: 提示された10種類の名称・順序、および例示された基準値（塩化物泉=溶存物質1000mg以上かつ陰イオン主成分が塩化物イオン、二酸化炭素泉=遊離炭酸1000mg以上、硫黄泉=総硫黄2mg以上、酸性泉=水素イオン1mg以上、放射能泉=ラドン8.25マッヘ以上）は**すべて一次情報と一致**しました。

### 2-1. 塩類泉の細別（陽イオン主成分による）

「主成分」とは**ミリバル（mval）値が最も大きいもの**をいいます。[指針2014] 1-3(1)

- **塩化物泉**: ナトリウム－／カルシウム－／マグネシウム－塩化物泉
  - うち **ナトリウムイオン5,500 mg/kg以上 かつ 塩化物イオン8,500 mg/kg以上**（塩化ナトリウムとして240.0 mval/kg以上）を「**ナトリウム－塩化物強塩泉**」
- **炭酸水素塩泉**: ナトリウム－／カルシウム－／マグネシウム－炭酸水素塩泉
  - 炭酸イオン（CO₃²⁻）が主成分の場合も「炭酸塩泉」とせず**炭酸水素塩泉**とする
- **硫酸塩泉**: ナトリウム－／マグネシウム－／カルシウム－／鉄(II,III)－／アルミニウム－硫酸塩泉
  - 酸性の硫酸塩泉は SO₄²⁻ と HSO₄⁻ の mval% を合計して主成分判定

### 2-2. 特殊成分の泉質名への付記規則

[指針2014] 1-3(3)3)・(4) より、オントロジーの命名規則として重要です。

- 水素イオン1 mg/kg以上を含む塩類泉 → 泉質名の先頭に「**酸性－**」を付記（例: 酸性－ナトリウム－硫酸塩泉）
- 総硫黄・二酸化炭素・ラドン・総鉄・よう化物イオンを限界値以上含む塩類泉 → 「**含二酸化炭素－**」「**含よう素－**」等を先頭に付記（例: 含よう素－ナトリウム－塩化物泉）
- **特殊成分を2種以上含む場合の表記順位**（原則）:
  1. 水素イオン →（酸性）
  2. 総硫黄 →（含硫黄）
  3. 遊離二酸化炭素 →（含二酸化炭素）
  4. ラドン →（含放射能）
  5. 総鉄イオン →（含鉄）
  6. よう化物イオン →（含よう素）
  - 例: 酸性・含硫黄－ナトリウム－硫酸塩泉／含硫黄・弱放射能－アルカリ性単純温泉
- **泉温による塩類泉の分類**: 泉温25℃未満の塩類泉は「…**冷鉱泉**」、25℃以上は「…**温泉**」（例: ナトリウム－塩化物強塩冷鉱泉）
- **硫黄泉の型区別**: 硫黄が遊離硫化水素の型で主として含有される場合「**硫化水素型**」と付記。判定式は
  `[H₂S] > [HS⁻] + [S₂O₃²⁻]`（各成分のモル濃度 mmol/kg）で比較
- **放射能泉の細分**: ラドン **8.25マッヘ単位以上50マッヘ単位未満**＝「**弱放射能**」、**50マッヘ単位以上**＝「**放射能**」

## 3. 泉温による分類

[指針2014] 1-2(1) p.3。鉱泉が地上に湧出したときの温度、または採取したときの温度を「泉温」といいます。

| 分類 | 泉温 |
|---|---|
| **冷鉱泉** | 25℃未満 |
| **低温泉**（温泉） | 25℃以上 34℃未満 |
| **温泉**（温泉） | 34℃以上 42℃未満 |
| **高温泉**（温泉） | 42℃以上 |

出典: [指針2014] https://www.env.go.jp/nature/onsen/pdf/2-5_p_14.pdf p.3

> **タスク前提の訂正**: タスクでは25〜34℃を「**微温泉**」としていましたが、鉱泉分析法指針（平成26年改訂）の正式名称は「**低温泉**」です。「微温泉」は指針の分類表には現れません。温度境界値（25／34／42℃）自体はタスク記載どおりで一致します。オントロジーでは正式名称「低温泉」を採用し、「微温泉」は別名（俗称）として扱うのが妥当です。
>
> なお表の構造上、「冷鉱泉」以外の3区分（低温泉・温泉・高温泉）が上位概念「温泉」に括られており、「温泉」という語が**上位概念**と**34-42℃の区分名**の両方に使われる二重性があります。オントロジー実装では名前空間の衝突に注意が必要です。

## 4. 液性（pH）による分類

[指針2014] 1-2(2) p.3。**湧出時のpH値**により分類します。

| 分類 | pH |
|---|---|
| **酸性** | pH 3未満 |
| **弱酸性** | pH 3以上 6未満 |
| **中性** | pH 6以上 7.5未満 |
| **弱アルカリ性** | pH 7.5以上 8.5未満 |
| **アルカリ性** | pH 8.5以上 |

出典: [指針2014] https://www.env.go.jp/nature/onsen/pdf/2-5_p_14.pdf p.3

**タスク前提の検証結果**: 提示された5区分と境界値はすべて一次情報と**完全一致**しました。

なお「アルカリ性単純温泉」の判定には**現地（湧出地）でのpH測定値8.5以上**が用いられます（[指針2014] 1-3(2)）。

## 5. 浸透圧による分類

[指針2014] 1-2(3) pp.3-4。**溶存物質（ガス性のものを除く）**または**凝固点（氷点）**により分類します。

| 分類 | 溶存物質（ガス性のものを除く） | 凝固点 |
|---|---|---|
| **低張性** | **8,000 mg/kg未満**（8 g/kg未満） | −0.55℃以上 |
| **等張性** | **8,000 mg/kg以上 10,000 mg/kg未満**（8〜10 g/kg） | −0.55℃未満 −0.58℃以上 |
| **高張性** | **10,000 mg/kg以上**（10 g/kg以上） | −0.58℃未満 |

出典: [指針2014] https://www.env.go.jp/nature/onsen/pdf/2-5_p_14.pdf pp.3-4

### 5-1. 併記の命名規則

[指針2014] は泉温・液性・浸透圧を次の順で分類命名すると例示しています。

```
例示:  等張性      中性      高温泉
      （浸透圧）  （液性）  （泉温）
```

この名称は**療養泉としての泉質名に併記するのが通例**です。
実際の温泉分析書の記載例（[指針2014] p.158）:

> `6. 泉質：含硫黄－ナトリウム・カルシウム－塩化物温泉（高張性弱アルカリ性高温泉）`

つまり掲示上の完全な泉質表記は `<泉質名>（<浸透圧><液性><泉温>）` という構造を取ります。オントロジーでは泉質名と3つの分類軸を独立プロパティとして持ち、表示時に合成するのが適切です。

## 6. 適応症と禁忌症（2014年（平成26年）環境省改正後）

### 6-1. 「一般的適応症」と「泉質別適応症」の違い

[掲示基準2014] 3.(1) は適応症を2階層で構成しています。

- **療養泉の一般的適応症**: **泉質を問わず**、療養泉であれば共通して掲示できる適応症（浴用のみ規定）
- **泉質別適応症**: **掲示用泉質ごとに**定められた適応症（浴用・飲用それぞれ規定）

**重複時の扱い**（[掲示基準2014] 3.(1) 注1・注2）:
- 一般的適応症と泉質別適応症が重複する場合、掲示に当たっては**泉質別適応症の掲示を優先**し、重複するものを一般的適応症から除いても差し支えない
- 療養泉の泉質分類が2つ以上該当する場合の適応症は「該当するすべての適応症」だが、掲示に当たっては**重複して掲げない**
  - 例: 含二酸化炭素－ナトリウム－塩化物泉は「塩化物泉」と「二酸化炭素を含む療養泉」に該当するため、浴用適応症の「きりきず、末梢循環障害、冷え性」は重複して掲げない

### 6-2. 温泉療養の前提（[掲示基準2014] 3.冒頭）

条文が明示する重要な限定であり、オントロジーの注記として保持すべき内容です。

1. 温泉療養の効用は、化学的因子・温熱その他の物理的因子・温泉地の地勢及び気候・利用者の生活リズムの変化その他諸般によって起こる**総合作用による心理反応などを含む生体反応**である
2. 温泉療養は、特定の病気を治癒させるよりも、**症状・苦痛の軽減、健康の回復・増進による全体的改善効用**を目的とする
3. 短期間でも精神的なリフレッシュなど相応の効用が得られるが、**十分な効用を得るためには通常2〜3週間**の療養期間が適当
4. 適応症でも、病期または療養者の状態によっては**悪化する場合がある**ので、専門的知識を有する医師の指示・指導のもとに行うことが望ましい
5. 適応症の効用は総合作用による生体反応によるもので、**温泉の成分のみによって効用を確定することは困難**であることから、掲示内容は引き続き**知事の判断に委ねる**

### 6-3. 療養泉の一般的適応症（浴用）

- 筋肉若しくは関節の慢性的な痛み又はこわばり（関節リウマチ、変形性関節症、腰痛症、神経痛、五十肩、打撲、捻挫などの慢性期）
- 運動麻痺における筋肉のこわばり
- 冷え性、末梢循環障害
- 胃腸機能の低下（胃がもたれる、腸にガスがたまるなど）
- 軽症高血圧
- 耐糖能異常（糖尿病）
- 軽い高コレステロール血症
- 軽い喘息又は肺気腫
- 痔の痛み
- 自律神経不安定症、ストレスによる諸症状（睡眠障害、うつ状態など）
- 病後回復期
- 疲労回復、健康増進

### 6-5. 禁忌症

**禁忌症の定義**（[掲示基準2014] 1.）:
> 禁忌症は、**1回の温泉入浴又は飲用でも有害事象を生ずる危険性がある病気・病態**である。なお、禁忌症にあたる場合でも、専門的知識を有する医師の指導のもとに温泉療養を行うことは妨げない。

禁忌症は **①一般的禁忌症、②泉質別禁忌症、③含有成分別禁忌症** の3階層で構成されます。

#### ① 温泉の一般的禁忌症（浴用）

- 病気の活動期（特に熱のあるとき）
- 活動性の結核、進行した悪性腫瘍又は高度の貧血など身体衰弱の著しい場合
- 少し動くと息苦しくなるような重い心臓又は肺の病気、むくみのあるような重い腎臓の病気
- 消化管出血、目に見える出血があるとき
- 慢性の病気の急性増悪期

#### ② 泉質別禁忌症

| 掲示用泉質 | 浴用 | 飲用 |
|---|---|---|
| **酸性泉** | 皮膚又は粘膜の過敏な人、高齢者の皮膚乾燥症 | — |
| **硫黄泉** | **酸性泉に同じ** | — |

**注目点**: 泉質別禁忌症が定められているのは**酸性泉と硫黄泉の2泉質のみ**で、いずれも浴用のみです。他の8泉質には泉質別禁忌症がありません。

#### ③ 含有成分別禁忌症（飲用のみ）

Aは温泉1kg中に含まれる各成分の重量（mg）。**浴用の禁忌はすべて「—」**です。

| 成分 | 飲用量の閾値 | 飲用禁忌症 |
|---|---|---|
| **ナトリウムイオン** | 1日 (1,200／A)×1,000 mL超 | 塩分制限の必要な病態（腎不全、心不全、肝硬変、虚血性心疾患、高血圧など） |
| **カリウムイオン** | 1日 (900／A)×1,000 mL超 | カリウム制限の必要な病態（腎不全、副腎皮質機能低下症） |
| **マグネシウムイオン** | 1日 (300／A)×1,000 mL超 | 下痢、腎不全 |
| **よう化物イオン** | 1日 (0.1／A)×1,000 mL超 | 甲状腺機能亢進症 |
| 上記のうち2つ以上に該当 | — | 該当するすべての禁忌症 |

**掲示省略規則**（[掲示基準2014] 2.(1)③ 注）: 飲用の1日総量は「およそ200〜500 mLまで」と定められているため、算出された**具体的限界値が500 mL以上の場合は、1日の飲用量を超えているため禁忌症を掲示することを要しない**。

原文の計算例: ナトリウムイオン3,000 mg/kg、カリウムイオン200 mg/kg、マグネシウムイオン60 mg/kg、よう化物イオン1 mg/kgを含有する温泉の場合
- 1日100 mL超（よう化物イオンから算出）: 甲状腺機能亢進症
- 1日400 mL超（ナトリウムイオンから算出）: 塩分制限の必要な病態
- カリウムイオン・マグネシウムイオンは算出値が500 mL以上となるため掲示不要

### 6-6. 浴用の方法及び注意（[掲示基準2014] 2.(2)①）

オントロジーの入浴プロトコル知識として一次情報の全項目を記録します。

**ア. 入浴前の注意**
- 食事の直前・直後及び飲酒後の入浴は避ける。酩酊状態での入浴は特に避ける
- 過度の疲労時には身体を休める
- 運動後30分程度の間は身体を休める
- 高齢者、子供及び身体の不自由な人は、1人での入浴は避けることが望ましい
- 浴槽に入る前に、手足から掛け湯をして温度に慣らすとともに、身体を洗い流す
- 入浴時、特に起床直後の入浴時などは脱水症状等にならないよう、あらかじめコップ一杯程度の水分を補給しておく

**イ. 入浴方法**
- **入浴温度**: 高齢者、高血圧症若しくは心臓病の人又は脳卒中を経験した人は、**42℃以上の高温浴は避ける**
- **入浴形態**: 心肺機能の低下している人は、全身浴よりも**半身浴又は部分浴**が望ましい
- **入浴回数**: 入浴開始後数日間は**1日当たり1〜2回**とし、慣れてきたら**2〜3回まで**増やしてもよい
- **入浴時間**: 入浴温度により異なるが、1回当たり、初めは**3〜10分程度**とし、慣れてきたら**15〜20分程度まで**延長してもよい

**ウ. 入浴中の注意**
- 運動浴を除き、一般に手足を軽く動かす程度にして静かに入浴する
- 浴槽から出る時は、立ちくらみを起こさないようにゆっくり出る
- めまいが生じ、又は気分が不良となった時は、近くの人に助けを求めつつ、浴槽から頭を低い位置に保ってゆっくり出て、横になって回復を待つ

**エ. 入浴後の注意**
- 身体に付着した温泉成分を温水で洗い流さず、タオルで水分を拭き取り、着衣の上、保温及び30分程度の安静を心がける
  - ただし、肌の弱い人は、**刺激の強い泉質（例えば酸性泉や硫黄泉等）**や必要に応じて**塩素消毒等**が行われている場合には、温泉成分等を温水で洗い流した方がよい
- 脱水症状等を避けるため、コップ一杯程度の水分を補給する

**オ. 湯あたり** → 項目9参照

**カ. その他**
- 浴槽水の清潔を保つため、浴槽にタオルは入れない

## 7. 飲用（飲泉）の適応症・禁忌・注意点

### 7-1. 飲泉できる泉質（泉質別適応症の飲用欄から導出）

[掲示基準2014] の泉質別適応症の**飲用欄に適応症が定められている泉質**は次の7種です。

| 飲用適応症がある泉質 | 飲用適応症 |
|---|---|
| **塩化物泉** | 萎縮性胃炎、便秘 |
| **炭酸水素塩泉** | 胃十二指腸潰瘍、逆流性食道炎、耐糖能異常（糖尿病）、高尿酸血症（痛風） |
| **硫酸塩泉** | 胆道系機能障害、高コレステロール血症、便秘 |
| **二酸化炭素泉** | 胃腸機能低下 |
| **含鉄泉** | 鉄欠乏性貧血 |
| **含よう素泉** | 高コレステロール血症 |
| **硫黄泉** | 耐糖能異常（糖尿病）、高コレステロール血症 |

**飲用適応症が定められていない泉質（3種）**: 単純温泉、酸性泉、放射能泉

> **重要な解釈上の注意**: 上表は「飲用適応症が掲示できる泉質」であり、「その泉質なら飲泉して良い」という意味ではありません。飲泉には**温泉法第18条に基づく飲用利用の許可**が別途必要です。[掲示基準2014] は「**飲用利用許可を取得していない施設には原則的に飲用の禁忌症、適応症および飲用の注意事項を記載しないこと**」と明記しています（[指針2014] p.158近傍の掲示解説部）。オントロジーでは「泉質の飲用適応症」と「施設の飲用許可」を別クラスとして分離すべきです。

### 7-2. 飲用の方法及び注意（[掲示基準2014] 2.(2)②）

前文: 温泉は湧出後、時間の経過とともに変化がみられるため、地中から湧出した直後の新鮮な温泉が最も効用があるといわれているが、**それぞれの泉質に適する用い方をしなければ、かえって身体に不利に作用する場合もある**。

- **ア.** 飲泉療養に際しては、**専門的知識を有する医師の指導を受ける**こと。服薬治療中の人は、主治医の意見を聴くこと
- **イ.** **15歳以下の人については、原則的には飲用を避ける**こと（専門的知識を有する医師の指導を受ける飲泉は例外）
- **ウ.** 飲泉は決められた場所で、**源泉を直接引いた新鮮な温泉**を飲用すること
- **エ.** 温泉飲用の**1回の量は一般に100〜150 mL程度**とし、その**1日の総量はおよそ200〜500 mLまで**とすること
  - **注1**: 温泉に**ひ素、銅、ふっ素、鉛及び水銀並びに遊離炭酸**が含まれる場合は、この記載に加えて、別に定める方法により飲用量を示す
  - **注2**: 温泉が**pH3未満**である場合（希釈により飲用時にpH3以上になっている場合を除く）は、この記載に代えて「この温泉の液性は酸性であるため、真水で**pH3以上**となるようおおよそA倍に薄めた上で、飲用の1回の量は**100 mLまで**とし、その1日の総量はおよそ200〜500 mLまでとすること」とする
- **オ.** 飲泉には、自身専用又は使い捨てのコップなど衛生的なものを用いること
- **カ.** 飲泉は一般に**食事の30分程度前**に行うことが望ましいこと
- **キ.** 飲泉場から**飲用目的で温泉水を持ち帰らない**こと
- **ク.** 飲用する際には、**誤嚥に注意**すること（誤嚥＝うがいや焦って飲むことなどにより、肺や気管に水分を吸い込んでしまうこと。**嚥下障害を発症している人は飲泉を行わないこと**）

### 7-3. 飲用許容量（[飲用基準] 温泉利用基準・第二 飲用利用基準）

基準の適用対象となる成分は **ひ素、銅、ふっ素、鉛、水銀、遊離炭酸** の6種。
Aは当該温泉の1kg中に含まれる成分の重量（mg単位）の数値。

**大人（16歳以上の者）** — 湯治のために飲用する場合、次の量を超えないこと

| 成分 | 飲用の総量（1日につき） | 成分の総摂取量 |
|---|---|---|
| ひ素 | (0.1/A)×1000 mL | 0.1 mg |
| 銅 | (2.0/A)×1000 mL | 2 mg |
| ふっ素（フッ化物イオン） | (1.6/A)×1000 mL | 1.6 mg |
| 鉛 | (0.2/A)×1000 mL | 0.2 mg |
| 水銀 | (0.002/A)×1000 mL | 0.002 mg |
| 遊離炭酸 | — | **1,000 mg（1回につき）** |

**小人（15歳以下の者）**: 知見が必ずしも十分にないため、**原則的には飲用を避ける**こと。例外的に飲用する場合には医師の指導を受けること。

**微生物学的衛生管理の基準値**（飲泉口で採取、年1回以上検査）

| 検査項目 | 基準値 |
|---|---|
| 一般細菌 | 1 mLの検水で形成される集落数が **100以下** |
| 大腸菌群 | **検出されないこと** |
| 全有機炭素（TOC） | **5 mg/L以下** |

その他: 強酸強アルカリの温泉を飲用に供する場合は特に希釈・容量等を明示すること。炭酸ガスを含有する温泉については、**大量の炭酸の飲用吸収による「鉱泉酩酊」**について十分な注意を促すこと。複数の成分により飲用許容量が制限される場合、**最少量の飲用許容量を掲示**すること。

## 8. 湯使いの表示と日本温泉協会の天然温泉表示

### 8-1. 法定の掲示事項（温泉法第18条・温泉法施行規則第10条）

**温泉法第18条第1項**: 温泉を公共の浴用又は飲用に供する者は、施設内の見やすい場所に、環境省令で定めるところにより、①温泉の成分、②禁忌症、③入浴又は飲用上の注意、④前三号のほか入浴又は飲用上必要な情報として環境省令で定めるもの、を掲示しなければならない。

**温泉法施行規則第10条第1項** — 掲示すべき9項目:
1. 源泉名
2. 温泉の泉質
3. 源泉及び温泉を公共の浴用又は飲用に供する場所における温泉の温度
4. 温泉の成分
5. 温泉の成分の分析年月日
6. 登録分析機関の名称及び登録番号
7. 浴用又は飲用の禁忌症
8. 浴用又は飲用の方法及び注意
9. 次項各号に掲げる事項（＝下記の湯使い4項目）

**温泉法施行規則第10条第2項** — 法第18条第1項第4号の環境省令で定める情報（**湯使いの表示**）:

| # | 掲示対象 | 掲示内容 |
|---|---|---|
| 1 | **加水** — 温泉に水を加えて公共の浴用に供する場合 | その旨及び**その理由** |
| 2 | **加温** — 温泉を加温して公共の浴用に供する場合 | その旨及び**その理由** |
| 3 | **循環（ろ過）** — 温泉を循環させて公共の浴用に供する場合 | その旨（**ろ過を実施している場合は、その旨を含む**）及び**その理由** |
| 4 | **入浴剤添加・消毒** — 温泉に入浴剤（着色し、着香し、又は入浴の効果を高める目的で加える物質。ただし入浴する者が容易に判別することができるものを除く。）を加え、又は温泉を消毒して公共の浴用に供する場合 | **当該入浴剤の名称又は消毒の方法**及び**その理由** |

出典: [法令] https://www.env.go.jp/nature/onsen/pdf/2-5_p_1r.pdf ／ [施行規則] https://elaws.e-gov.go.jp/document?lawid=323M40000100035_20200330_502M60001000009
[掲示基準2014] 4.留意事項でも「なお、**加水、加温、循環（ろ過）、消毒、入浴剤添加**については、温泉法施行規則第10条に基づき、公共の浴用に供する場合は、**その旨及びその理由**を掲示する必要がある」と再確認されています。

**関連する法定要件**
- 掲示は**登録分析機関**の行う温泉成分分析の結果に基づく（温泉法第18条第2項）
- 温泉成分分析を受けるべき期間は**前回の分析を受けた日から10年以内**（温泉法施行令第1条）
- 分析結果の通知を受けた日から**30日以内**に掲示内容を変更（温泉法第18条第3項）
- 掲示・変更しようとするときは**あらかじめ都道府県知事へ届け出**（温泉法第18条第4項）

### 8-2. 「源泉かけ流し」の位置づけ

**重要**: 「**源泉かけ流し**」は**法令上の定義が存在しません**。温泉法施行規則第10条第2項が掲示を義務づけるのは上記の**加水・加温・循環（ろ過）・入浴剤添加・消毒の5類型**のみで、「源泉かけ流し」という表示区分・定義規定は温泉法・施行令・施行規則・鉱泉分析法指針・掲示基準通知のいずれにも見当たりませんでした（[法令] [指針2014] [掲示基準2014] を全文検索して確認）。

したがって「源泉かけ流し」は**業界・事業者による自主的な広告表示**であり、その内容は法定4類型の**非該当（加水なし・加温なし・循環ろ過なし等）として間接的に読み取るしかありません**。一般的な理解として「循環ろ過をせず、常に新しい源泉を浴槽に注ぎ入れて溢れさせ、湯の再利用を行わない状態」を指すとされますが、これは二次情報に基づく通俗的定義です（例: https://onsen.nifty.com/onsen-matome/231013904524/ が「温泉法で明確な定義が決まっているわけではありません」と明記）。

**オントロジー設計上の推奨**: 「源泉かけ流し」を独立した検証可能な属性として扱わず、法定掲示4類型（加水／加温／循環ろ過／消毒・入浴剤）の**否定の組み合わせから導出される派生属性**、あるいは「事業者の自称ラベル」として法定属性と明確に区別してモデル化すべきです。

## 9. 「湯あたり」と連続入浴の注意

### 9-1. 「湯あたり」の公的な説明（信頼度：高）

[掲示基準2014] 2.(2)① オ「湯あたり」が唯一の公的定義に相当する記述です。

> **オ．湯あたり**
> 温泉療養開始後**おおむね3日〜1週間前後**に、**気分不快、不眠若しくは消化器症状等の湯あたり症状又は皮膚炎**などが現れることがある。このような状態が現れている間は、**入浴を中止するか、又は回数を減らし、このような状態からの回復を待つこと。**

出典: [掲示基準2014] https://www.env.go.jp/nature/onsen/pdf/2-5_p_11.pdf p.4
独立検証: [JSA-入浴] https://www.spa.or.jp/onsen/1632/ 「５．湯あたり」に**同一の文言**が掲載されており一致しました。

**構造化のポイント**
- **発現時期**: 温泉療養開始後おおむね3日〜1週間前後
- **症状**: 気分不快／不眠／消化器症状等／皮膚炎
- **対処**: 入浴の中止、または回数の減少、回復を待つ

### 9-2. 「はしご湯」・連続入浴の注意（**一部未確認**）

**「はしご湯」という用語自体は、調査した一次情報（温泉法、温泉法施行規則、鉱泉分析法指針（平成26年改訂）、掲示基準2014、温泉利用基準、日本温泉協会の各解説ページ）には出現しませんでした。「はしご湯」の公的定義は未確認です。** 短時間に複数の浴場・浴槽を巡る行為を指す**俗語**と理解されます（「湯めぐり」も同様に公的定義は未確認）。

一方、**連続入浴・多回数入浴に対する注意は一次情報に明確な根拠があります**。以下は [掲示基準2014] の条文から直接導かれる、はしご湯に適用可能な制約です。

| 一次情報の規定 | 内容 | はしご湯への含意 |
|---|---|---|
| 入浴回数（2.(2)①イ(ウ)） | 入浴開始後**数日間は1日1〜2回**、慣れてきたら**2〜3回まで** | 1日に多数の浴場を巡る行為は、この上限（初期1〜2回、最大2〜3回）を容易に超過する |
| 入浴時間（2.(2)①イ(エ)） | 1回当たり初めは**3〜10分程度**、慣れてきたら**15〜20分程度まで** | 1回ごとの時間管理が必要 |
| 入浴前の注意（2.(2)①ア(イ)） | **過度の疲労時には身体を休める**こと | 巡浴による累積疲労時は入浴を控える根拠 |
| 入浴後の注意（2.(2)①エ(ア)） | 着衣の上、保温及び**30分程度の安静**を心がける | 各入浴の間に30分程度の安静が想定されており、連続的な巡浴と両立しにくい |
| 入浴後の注意（2.(2)①エ(イ)） | 脱水症状等を避けるため、**コップ一杯程度の水分を補給** | 回数に比例して脱水リスクが累積 |
| 入浴温度（2.(2)①イ(ア)） | 高齢者、高血圧症・心臓病の人、脳卒中経験者は**42℃以上の高温浴を避ける** | 高温泉（42℃以上）を含む巡浴では対象者に該当する制約 |
| 湯あたり（2.(2)①オ） | 症状出現中は**入浴を中止するか回数を減らす** | 巡浴の中断判断基準 |
| 刺激の強い泉質（2.(2)①エ(ア)） | **酸性泉や硫黄泉等**は肌の弱い人は温水で洗い流した方がよい | 異なる泉質を連続利用する際の皮膚負担 |

**オントロジー設計上の推奨**: 「はしご湯」を公的概念として扱わず、**俗語ラベル**として登録し、その注意事項は上記の法定入浴プロトコル（入浴回数上限・入浴時間・入浴間の安静時間・水分補給・湯あたり）への参照として表現するのが、出典の追跡可能性を保つ上で適切です。

### 10-2. 掲示内容の根拠（源泉 vs 利用施設）

[掲示基準2014] 4.留意事項:
- 温泉は自然由来であり、ゆう出後の酸化・揮発性成分の揮散等により成分が変化するため、**恒常的に分析結果を示すことは困難**
- 掲示内容は**利用施設における成分分析結果に基づくことを原則**とするが、ゆう出口と利用施設との間で成分に差異がないと認められる場合は、**ゆう出口における分析結果に基づき掲示して差し支えない**
- **源泉の分析結果に基づき適応症を判断した場合は、その旨が温泉利用者に分かるようにすること**

**オントロジー設計上の含意**: 成分値には**測定地点（源泉／利用施設）**と**分析年月日**を必ず属性として持たせる必要があります。同一施設でも源泉ベースと浴槽ベースで値が異なりうるため、成分値を源泉エンティティに直接ぶら下げる単純なモデルは不十分です。

### 10-3. 適応症掲示の裁量性

[掲示基準2014] は適応症について「その掲示の内容については引き続き**知事の判断に委ねる**」（3.⑤）とし、掲示手続も「都道府県、保健所設置市又は特別区が必要に応じて定める手続を経る」（3.(3)）としています。また「一般的適応症及び泉質別適応症のほか**伝統的適応症**を適応症として決定する場合は、専門的知識を有する医師の意見を参考とすることが望ましい」とも規定しています。

**含意**: 泉質→適応症のマッピングは**決定論的ではなく**、実際の掲示内容は自治体・施設によって変動しえます。オントロジーでは「基準上の泉質別適応症」（規範）と「個別施設の実際の掲示内容」（実測）を分離すべきです。「伝統的適応症」という第3のカテゴリの存在にも注意が必要です。

### 10-4. 分析上の注意（データ品質）

[指針2014] の注記から、成分データの品質に関わる論点:
- 溶存物質にガス性のもの（遊離二酸化炭素、遊離硫化水素）を含めてはならない。**蒸発残留物の値を「溶存物質（ガス性のものを除く）」としない**
- 海岸直近の井戸で泉温25℃未満・溶存物質1,000 mg/kg以上の場合、**現世の海水を温泉と判定しないよう注意**（化石水タイプは硫酸イオン濃度が著しく低下しており、Mg/Caモル濃度比が1を超えないことを基準とする判定例がある）
- ラドン測定は **IM泉効計** または **液体シンチレーションカウンタ** を用い、**測定に用いた方法を分析書に明記**すること。ラドンの規定値は**放射能濃度**である
- 現地pHが9.7以上の場合、メタけい酸水素イオン・メタけい酸イオンの値はメタけい酸として計算して判定する
